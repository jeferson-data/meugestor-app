# 💰 MeuGestor — Gestão financeira simples para pequenas empresas

Aplicação web para controle de fluxo de caixa, movimentações, pagamentos e gestão operacional de pequenos negócios.

🔗 **Acesse:** [meugestor-app.vercel.app](https://meugestor-app.vercel.app)

---

## ✨ O que você pode fazer

- 📊 **Dashboard com indicadores financeiros** em tempo real
- 💸 **Lançamento e consulta de movimentações** (entradas e saídas)
- 📋 **Extrato e conciliação** de registros
- 🏢 **Cadastro e gerenciamento de empresas**
- 💳 **Controle de pagamentos**, assinaturas e planos
- 👥 **Cadastro de vendedores e pedidos**
- 🔐 **Autenticação segura** e controle de acesso por usuário
- 📱 **Layout responsivo** — funciona no computador e no celular
- 📝 **Registro de auditoria** para acompanhamento das ações

---

## 🎯 Para quem é

- 🏪 Pequenas empresas de bairro
- 🧾 MEIs e autônomos
- 🛒 Comércios locais que precisam organizar o fluxo de caixa
- 📈 Negócios que querem sair da planilha e ter um sistema simples

## 🛠️ Tecnologias utilizadas

| Tecnologia | Uso no projeto |
|------------|----------------|
| **React 19** | Interface do usuário |
| **Vite** | Build e desenvolvimento |
| **Supabase** | Autenticação e banco de dados |
| **Tailwind CSS** | Estilização |
| **Recharts** | Gráficos e dashboards |
| **React Router** | Navegação entre páginas |
| **Lucide React** | Ícones |
| **Oxlint** | Qualidade de código |
