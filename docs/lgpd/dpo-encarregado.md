# Encarregado de Dados (DPO)

## O que é o encarregado

A LGPD (art. 41) exige que todo controlador indique um **Encarregado
pelo Tratamento de Dados Pessoais** (DPO). É a pessoa responsável por:

- Receber solicitações dos titulares
- Receber comunicações da ANPD
- Orientar a equipe sobre boas práticas de proteção de dados
- Ser o canal de comunicação entre o MeuGestor, os titulares e a ANPD

## Atribuições do encarregado

- [ ] Responder pedidos de titulares em até 15 dias corridos
- [ ] Manter este documento atualizado
- [ ] Revisar o inventário de dados a cada 6 meses
- [ ] Coordenar resposta a incidentes de segurança
- [ ] Ser o contato com a ANPD em caso de fiscalização
- [ ] Orientar funcionários e vendedores sobre boas práticas

## Se você não é advogado (caso do MeuGestor)

O encarregado **não precisa ser advogado**, mas precisa saber:

- Os direitos dos titulares (art. 18)
- O prazo de resposta (15 dias)
- Quando consultar um advogado (incidentes graves, dúvidas jurídicas)
- Como registrar tudo (para prova futura)

**Recomendação:** para casos complexos (vazamento de dados, pedido de
exclusão com dados de terceiros, questionamento da ANPD), consulte um
advogado especializado em LGPD antes de responder.

## Comunicação com a ANPD

Em caso de incidente de segurança que possa acarretar risco ou dano
relevante aos titulares, o MeuGestor deve comunicar a ANPD em prazo
razoável (a ANPD recomenda até 3 dias úteis a partir do conhecimento
do incidente).

**Canal oficial:** https://www.gov.br/anpd/
