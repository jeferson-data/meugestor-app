# Procedimento de Atendimento a Titulares

**Versão:** 1.0
**Data:** 2026-09-23

Este documento descreve como o MeuGestor atende os pedidos dos titulares
de dados, conforme a LGPD (arts. 18 e 19).

## Direitos dos titulares

| Direito | Como o MeuGestor atende | Prazo |
|---------|-------------------------|-------|
| Confirmação de tratamento | O titular vê seus dados no sistema | Imediato |
| Acesso aos dados | Exportação em CSV dentro do app | Imediato |
| Correção | O titular edita seus dados no sistema | Imediato |
| Anonimização / bloqueio | Fluxo de exclusão de conta | Imediato |
| Eliminação | Fluxo de exclusão de conta (com retenção fiscal) | Imediato |
| Portabilidade | Exportação em CSV | Imediato |
| Informação sobre compartilhamento | Política de Privacidade | — |
| Revogação de consentimento | Não aplicável (não usamos consentimento) | — |

## Como o titular faz um pedido

O titular pode exercer seus direitos por três caminhos:

1. **Diretamente no sistema** (preferencial)
   - Acessa os dados, corrige, exporta ou exclui sozinho
   - Sem necessidade de contato

2. **Por e-mail para o encarregado**
   - Endereço: _[preencher]_
   - Deve informar: nome, e-mail cadastrado, o que deseja

3. **Por e-mail para o suporte**
   - Redirecionamos para o encarregado

## Fluxo de atendimento

### 1. Recebimento (dia 0)

- Registrar o pedido em planilha interna (data, nome, e-mail, tipo, prazo)
- Responder confirmando o recebimento em até 1 dia útil
- Informar o prazo: até 15 dias corridos (LGPD art. 19)

### 2. Verificação de identidade (dia 1)

Antes de atender, confirmar que quem pediu é realmente o titular:

- Se veio do e-mail cadastrado → já é prova razoável
- Se veio de outro e-mail → pedir confirmação por e-mail para o
  endereço cadastrado
- Em caso de dúvida → solicitar documento ou pergunta de segurança
  (data da última movimentação, valor de um lançamento específico)

### 3. Atendimento (dias 2 a 10)

Dependendo do tipo de pedido:

**Confirmação / acesso:**
- Orientar a usar a exportação no próprio sistema
- Se o titular não conseguir, enviar CSV por e-mail

**Correção:**
- Orientar a editar no sistema
- Se for algo que o titular não consegue editar, corrigir manualmente

**Exclusão:**
- Orientar a usar o fluxo de exclusão no sistema
- Explicar que dados financeiros são retidos por 5 anos
- Registrar a solicitação

**Portabilidade:**
- Enviar CSV com todas as movimentações
- Formato aberto, legível por máquina

### 4. Resposta final (dia 10 a 15)

- Enviar resposta formal ao titular
- Informar o que foi feito
- Se negado, justificar com base legal
- Arquivar o histórico
